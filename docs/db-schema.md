# Database schema (D1 `ping`)

Migrations in `migrations/`, applied on every deploy (`npm run deploy`). Migrations are append-only: never edit
one that has been deployed; add a new one.

## `notas`

| Column | Type | Rules |
| --- | --- | --- |
| `id` | TEXT PK | UUID, generated by the client when possible (ADR-0007) |
| `texto` | TEXT NOT NULL | trimmed, 1..2000 chars (enforced in code) |
| `creado` | TEXT NOT NULL | ISO 8601 UTC |
| `actualizado` | TEXT NOT NULL | ISO 8601 UTC, refreshed on every update |
| `version` | INTEGER NOT NULL DEFAULT 1 | +1 on every update; updates require the current value (ADR-0005) |
| `borrado_en` | TEXT NULL | soft delete timestamp; NULL = visible (ADR-0006) |

Index `notas_visibles (borrado_en, creado)` for the visible-notes listing.

## `cambios` (audit log, part of the template)

| Column | Type | Rules |
| --- | --- | --- |
| `id` | INTEGER PK AUTOINCREMENT | |
| `ts` | TEXT NOT NULL | ISO 8601 UTC, same as the write it records |
| `actor` | TEXT NOT NULL | `pwa` \| `mcp` \| `script` (CHECK) |
| `operacion` | TEXT NOT NULL | e.g. `crear`, `editar`, `borrar` |
| `entidad` | TEXT NOT NULL | table name, e.g. `notas` |
| `entidad_id` | TEXT NOT NULL | id of the changed row |
| `antes` | TEXT NULL | JSON snapshot before (NULL on create) |
| `despues` | TEXT NULL | JSON snapshot after |

Index `cambios_entidad (entidad, entidad_id)`.

Rows are inserted in the same batch as the write, with `WHERE changes() = 1` (ADR-0006). Never updated or deleted.
