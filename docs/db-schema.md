# Database schema (D1 `ping`)

Migrations in `migrations/`, applied on every deploy (`npm run deploy`). Migrations are append-only: never edit
one that has been deployed; add a new one. Names in English (ADR-0010, English for code, API and database).

## `notes`

| Column | Type | Rules |
| --- | --- | --- |
| `id` | TEXT PK | UUID, generated by the client when possible (ADR-0007, Idempotent creation with client-generated ids) |
| `text` | TEXT NOT NULL | trimmed, 1..2000 chars (enforced in code) |
| `created_at` | TEXT NOT NULL | ISO 8601 UTC |
| `updated_at` | TEXT NOT NULL | ISO 8601 UTC, refreshed on every update |
| `version` | INTEGER NOT NULL DEFAULT 1 | +1 on every update; updates require the current value (ADR-0005, Optimistic concurrency with an integer `version`) |
| `deleted_at` | TEXT NULL | soft delete timestamp; NULL = visible (ADR-0006, Soft delete and audit log) |

Index `notes_visible (deleted_at, created_at)` for the visible-notes listing.

## `audit_log` (part of the template)

| Column | Type | Rules |
| --- | --- | --- |
| `id` | INTEGER PK AUTOINCREMENT | |
| `changed_at` | TEXT NOT NULL | When the change happened (ISO 8601 UTC). Equals the row's `updated_at` after that write |
| `actor` | TEXT NOT NULL | Who made it: `pwa` \| `mcp` \| `script` (CHECK) |
| `operation` | TEXT NOT NULL | `create`, `update` or `delete` |
| `entity` | TEXT NOT NULL | table name, e.g. `notes` |
| `entity_id` | TEXT NOT NULL | id of the changed row |
| `before_json` | TEXT NULL | The whole row as JSON before the change (NULL on create) |
| `after_json` | TEXT NULL | The whole row as JSON after the change |

Index `audit_log_entity (entity, entity_id)`.

Rows are inserted in the same batch as the write, with `WHERE changes() = 1` (ADR-0006). Never updated or deleted.
