# ADR-0003: Stack

- Status: Proposed
- Date: 2026-11-24

## Context
The systems must cost $0/month at personal scale, run on infrastructure Joaquin owns, be reachable from Android,
and be easy for Claude to build and maintain. Joaquin approved TypeScript.

## Decision
- **Runtime:** Cloudflare Workers (personal account, Free plan). **Database:** D1 (SQLite), one per system.
- **Language:** TypeScript, strict mode. Types for bindings generated by `wrangler types`.
- **HTTP:** Hono. **Auth helpers:** `jose` for JWT verification.
- **Tests:** Vitest with `@cloudflare/vitest-plugin`, running inside the Workers runtime with a real local D1.
- **Client:** PWA in plain HTML/CSS/JS served as Worker static assets; no framework and no build step unless a
  system needs one.
- **CI:** GitHub Actions runs typecheck + tests on every PR (no secrets).

## Consequences
- Static assets are free and unlimited; only `/api/*` counts against the 100k requests/day Free limit.
- Plain JS in the client means no client-side type checking; PWA behavior is verified with a manual checklist
  until browser tests are added.
